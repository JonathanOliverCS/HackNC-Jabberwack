**Jabberwack — 2D Browser Game** | HTML, JavaScript  
*HackNC Hackathon, UNC-Chapel Hill*  
[GitHub Repository](https://github.com/JonathanOliverCS/HackNC-Jabberwack)

- Developed a three-level, 2D sprite-based PvE game with progressively increasing enemy counts across levels.
- Implemented an arc-shaped spell attack with damage mechanics that vary based on the player's movement state.
- Built health-based combat mechanics for the player and enemies, with 15 health points per character.
